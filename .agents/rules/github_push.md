# Rule: Always Push Changes to GitHub

- **Mandated Behavior**: After making any source code edits, feature additions, or bug fixes in this project, you MUST automatically run the git commands to add, commit, and push the changes to GitHub (`origin main`).
- **Commands**:
  1. `git add .`
  2. `git commit -m "<descriptive message>"`
  3. `git push origin main`
- **Enforcement**: Never wait for the user to explicitly ask to push to GitHub; always push immediately after completing an update.
